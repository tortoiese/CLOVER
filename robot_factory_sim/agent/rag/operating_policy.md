# 운영안 비교 기준 v1

## 비용과 ROI 산식
본 GUI의 매출 단위는 완료 공정 작업 1건이다. 완제품 판매량과 동일하다고 가정하지 않는다.
보충 전력 추정(Wh) = 이동·작업 배터리 소모(상대 단위) × 단위당 Wh / 충전효율.
전력 비용(원) = 보충 전력(Wh) / 1000 × 전력 단가(원/kWh).
이동 운영비 = 이동거리(m) × 이동 단가(원/m). 이동 단가는 전력 비용을 제외한다.
총투입비용 = 전력 비용 + 이동 운영비 + 평가 기간 고정비 + AI 사용비.
고정비에 인건비·설비·로봇·충전기 감가상각을 포함할지 사용자가 명시한다.
순이익 = 완료 공정 작업 수 × 건당 매출 - 총투입비용.
건당 순이익 = 순이익 / 완료 공정 작업 수.
운영비 기준 ROI(%) = 순이익 / 총투입비용 × 100. 설비 투자 ROI와 구분한다.
전력 대비 순이익 = 순이익 / 보충 전력(Wh). 분모 0이면 미산정이다.
반복 실험 표는 각 실험에서 계산한 지표의 평균이다. 평균 ROI는 합산 매출/비용 ROI와 다를 수 있다.
AI비는 추천안 1회 평가 기간의 추가 비용이다. 실제 토큰 사용료 자동 계측은 아직 없다.

## 최적화와 충전 기준
Rolling Horizon MILP v1은 현재 유휴 로봇과 대기 작업의 배정을 재계산한다.
계획 구간 내 예상 이동·작업 시간이 가능한 배정 후보만 선택한다.
로봇 1대당 최대 1개 작업, 작업당 최대 1개 로봇, 사용 가능한 설비당 최대 1개 신규 배정을 적용한다.
작업·충전소 복귀에 필요한 예상 에너지와 배터리 여유 10%를 확인한다.
배정 수를 우선 최대화하고 그다음 우선순위·이동·예상 에너지 점수를 줄인다. 전체 ROI 직접 최적화는 아니다.
충전 시점·충전소 선택은 기존 예측 충전 규칙이다. 충전 슬롯 제한은 SimPy 자원에서 강제한다.
설비 위치·충전소 대수 최적화 및 전체 공정 순서의 전역 최적화는 이번 모델에 포함하지 않는다.

## 비교와 오차 해석
비교는 GUI 공장 설정을 복사하고 기본 배치·만충전으로 시작하는 독립 실험이다.
동일한 남은 주문을 두 정책에 입력한다. 주문이 없으면 동일한 합성 포아송 도착을 주입한다.
작업별 공통 처리시간 난수를 고정한다. 재계획 중인 실제 실행을 이어서 예측하는 것은 아니다.
MILP 격차는 개별 배정 모델의 목적함수 격차다. 전체 운영 기간 ROI 최적성이나 실제 공장 오차가 아니다.
순이익 차이 95% t 신뢰구간은 독립 시드 반복의 평균 정책 차이에 대한 구간이다.
이는 개별 미래 실행의 예측구간이나 실측 대비 오차 범위가 아니다. 작은 반복 수에서는 불안정할 수 있다.
모델은 이동·작업 에너지만 계측하고 유휴전력·설비전력은 계측하지 않는다.
사용자 단가 및 Wh 환산값은 실측 검증 전까지 가정값이다. 예시값 사용 시 가상 비용 모델로 표시한다.
개선이 관측되지 않거나 순이익 증가가 불확실하면 추천을 보류한다. AI가 개선 수치를 생성하지 않는다.
